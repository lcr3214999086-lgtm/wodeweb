# 产品管理

后台入口：`/admin/core/product/`，菜单为“产品管理 → 产品列表”。

- 可新增和编辑名称、分类、标识、简介、特点、选型说明与产品图片。
- 产品特点每行填写一项；排序数字越小越靠前。
- 新产品默认下架。勾选“已上架”后显示于官网；支持批量上架与下架。
- 下架保留数据，公开接口不返回下架产品。编辑权限由 Django 用户与组权限控制。
- 已将原四项产品展示内容迁入数据库。后台保存后刷新首页或产品页即可更新，无需重新构建。

公开接口：`GET /api/products/`，返回 `products` 数组。匿名访客只能读取，产品修改通过后台执行。

图片保存于 `media/products/`。本地开发由 Django 提供 `/media/`；正式部署需为媒体文件配置持久化存储和 Web 服务。数据库与媒体文件应一起备份。
